Wisdom Wave

AI-Powered Educational Assistant with LLaMA 7B and RAG

LLaMA 7B Ollama LangChain ChromaDB React.js Flask

Project Overview

Wisdom Wave is an AI platform that delivers personalized, textbook-based answers to enhance learning. It integrates LLaMA 7B through Ollama for efficient LLM handling, using Retrieval-Augmented Generation (RAG) architecture to provide accurate, context-aware responses from educational materials.

Live Demo GitHub Repo

System Architecture

Frontend

React.js interface with:

  • User authentication
  • Textbook upload
  • Chat-style Q&A

Backend

Flask API handling:

  • LLM inference
  • Vector database ops
  • User management

AI Pipeline

RAG workflow:

  • Text embedding (ChromaDB)
  • Context retrieval
  • LLaMA 7B response gen

Key Features

📚 Textbook-Specific Answers

Users upload course materials, and Wisdom Wave provides answers directly referencing the content, reducing hallucinations by 40% compared to base LLM.

🔍 Step-by-Step Reasoning

Implements Chain-of-Thought prompting to break down complex problems into understandable steps (12% ROUGE-L improvement).

⚡ Efficient Inference

Quantized LLaMA 7B via Ollama achieves 2.5x faster response times compared to vanilla HuggingFace implementation.

Challenges & Solutions

Challenge: LLM Hallucinations

Solution: Implemented RAG with textbook embeddings and added confidence scoring to highlight uncertain answers.

Challenge: Slow Inference

Solution: Used 4-bit quantization via llama.cpp and optimized prompt engineering.
